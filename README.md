# Sonia’s Catering website preview

Static catering website with a food gallery, sample menus and WhatsApp enquiries.

## Publish

In repository Settings > Pages, select **Deploy from a branch**, branch **main**, folder **/(root)**.

## Files

- `index.html`: homepage
- `gallery.html`: complete photo gallery
- `assets/`: local styles, scripts, logos and photographs

Menus are illustrative. Reviews and event enquiries are prepared in the browser and handed off to WhatsApp. Google Analytics is not connected.
